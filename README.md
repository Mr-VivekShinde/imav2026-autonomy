# IMAV 2026 Autonomous Drone

Clean competition repository for the IMAV 2026 indoor autonomy stack.

Current scope:

- Mission 1: obstacle course
- Mission 2: dark-room inspection
- Mission 3: hot-spot detection and cone drop
- Mission 4: intentionally out of scope

Baseline stack:

- Ubuntu 24.04 container
- ROS 2 Jazzy
- Gazebo Harmonic
- PX4 SITL v1.17.0
- temporary x500 simulation model until the real CAD model is migrated

Start with `docs/SETUP.md`.
